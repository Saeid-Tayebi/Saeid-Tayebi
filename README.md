## What I work on

- Experimental decisions and prediction reliability when data are limited.

## Public tools

Each project below has an interactive example in my [portfolio lab](https://saeid-tayebi.github.io/lab.html?tool=missing). Run a prepared example or select a small CSV or Excel dataset from your computer. The original Python code runs in your browser.

| Project | Practical use |
| --- | --- |
| [HandiMissingDataEstimaor](https://github.com/Saeid-Tayebi/HandiMissingDataEstimaor) | Estimate missing measurements using PCA |
| [SelectivePCA](https://github.com/Saeid-Tayebi/SelectivePCA-Data-Reordering-Tool) | Rank variables by their additional variance contribution |
| [AutoPropensity](https://github.com/Saeid-Tayebi/AutoPropensity) | Fit and compare propensity models |
| [pca_nipals](https://github.com/Saeid-Tayebi/pca_nipals) | Explore multivariate structure with PCA |
| [pls_nipals](https://github.com/Saeid-Tayebi/pls_nipals) | Model relationships between inputs and outputs |
| [KMeansPro](https://github.com/Saeid-Tayebi/KMeansPro) | Explore groups of similar observations |
| [NullSpaceExplorer](https://github.com/Saeid-Tayebi/NullSpaceExplorer) | Explore alternative inputs for a modeled target |
| [cluster-based-pls](https://github.com/Saeid-Tayebi/cluster-based-pls) | Explore local predictive relationships with clustered PLS |
